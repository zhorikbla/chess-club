# Шахматный клуб

Учебная консольная информационная система на Java. Основная сущность —
регистрация игрока на турнир.

Проект намеренно начинаем с пустого Maven-каркаса. Модели, сервисы,
репозитории, SQL и консольное меню пишем последовательно и разбираем по мере
появления.

## Окружение

- JDK 17;
- Maven;
- PostgreSQL понадобится позже, когда дойдем до JDBC.

Проверка Java и Maven:

```bash
java -version
mvn -version
```

Компиляция:

```bash
mvn compile
```

После создания `Main.java` запуск будет выполняться командой:

```bash
mvn compile exec:java
```

Готовые черновики из приложенного архива сохранены только локально в
`.reference/` и исключены из Git.
